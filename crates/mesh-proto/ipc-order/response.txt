# The order of `IpcResponse`'s variants, pinned (DOC-8).
#
# postcard writes an enum as its variant's *position*, and several indices in
# `ipc.rs` are peeked rather than decoded — read from the first varint to route
# a frame before anything has parsed it. So a variant must never move: not
# deleted, not inserted in the middle, not reordered. Retire one by leaving a
# tombstone in its place (`Retired<Name>`, with no fields); add one at the end
# of the enum, then at the end of this file. `mesh-proto`'s `ipc_order` test
# fails until the two agree.
#
# The original reason was the Python SDK, a separate program that encoded
# requests by position. It went on 2026-09-20; the peeked indices did not.
